# eBook Guru

## Prerequisites

- Node.js (version X.X or higher)
- npm or yarn

## Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd ebook-guru
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

## Running the Project

### Development Mode
```bash
npm run dev
# or
yarn dev
```

### Production Mode
```bash
npm run build
npm start
# or
yarn build
yarn start
```
